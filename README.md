# GraLex Logistique — Website

A premium, fully responsive marketing website for **GraLex Logistique**, a logistics and
delivery company operating across Benin, Nigeria and the wider West African corridor.

Built with **pure HTML5, CSS3 and vanilla JavaScript** — no frameworks, no build step.

## 🌍 Live site
Published via GitHub Pages: **https://omai4x.github.io/gralex-logistique/**

## 📄 Pages
| Page | Description |
|------|-------------|
| `index.html` | Home — hero, services, process, testimonials, guarantees, CTA |
| `about.html` | Story, mission & vision, core values, timeline |
| `services.html` | All services + FAQ |
| `tracking.html` | Simulated real-time shipment tracking |
| `quote.html` | Validated quote request form |
| `gallery.html` | Filterable masonry gallery with lightbox |
| `contact.html` | Contact details, form, map, business hours |
| `blog.html` | Articles with search, filters and pagination |

## 🗂 Structure
```
├── *.html            # 8 pages
├── css/              # variables, style, animations, responsive
├── js/               # main, animations, slider, tracking, form
├── images/           # image assets (hero, services, gallery, icons, logo)
└── fonts/
```

## 🎨 Design
- **Fonts:** Poppins (headings) · Inter (body)
- **Palette:** navy `#0F172A`, blue `#2563EB`, orange `#F97316`, green `#16A34A`
- Fully responsive (ultrawide → small phones), accessible, SEO-ready.
